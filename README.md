# Hitech Advisors - Modernized Enterprise Web Platform

A state-of-the-art, high-performance clone and modernization of [hitechadvisors.com](https://hitechadvisors.com), built with **React 19 + TypeScript + Tailwind CSS v4 + Lucide Icons**.

## Features

- **Enterprise Design System**: Deep obsidian surfaces, signature Hitech crimson (`#D22931`), ambient subtle glows, and glassmorphism.
- **Interactive AI & Cloud Maturity Diagnostic**: Benchmark infrastructure, AI readiness, and growth bottlenecks.
- **Interactive Services Bento Grid**: Full capability breakdowns across Cloud & Security, Product Engineering, IT Systems & Operations, Talent Solutions, and Growth Acceleration.
- **Authentic Client Case Studies**: Quantified outcomes for Qualtrics, BuyWander, Gates Foundation, and inQbrands.
- **Continuous Client Marquee**: Showcasing enterprise partners (Microsoft, Cisco, Costco, Bank of America, Nintendo, T-Mobile, etc.).
- **Executive "2030" Event Hub**: Live panel recordings and instant RSVP booking.
- **Thought Leadership Engine**: In-modal article reader for executive whitepapers.
- **Strategic Consultation Modal**: Multi-step "Talk to an Expert" scheduler.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
